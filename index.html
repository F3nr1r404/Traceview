LIVE CAMERA TEST

The phone's rear camera becomes the glasses' camera. Both lenses show the live view with the same schematic overlay.

  1. Load a vehicle on the phone (Scan → send to glasses), then start the camera.
  2. Stand at the side of the truck so the steer axle and the first drive axle are both in view.
  3. Tap the center of the steer wheel hub, then the center of the first drive-axle hub. The overlay locks to the truck.
  4. Drag to slide it, scroll or pinch to scale it. Say “align” to redo it. Tap ⛶ for glasses-only full screen.

⚠ Camera blocked in this viewerClaude's artifact viewer does not let pages use the camera. To run this live on your phone, open the same page from a regular https web address (for example a free Netlify Drop or GitHub Pages link). The standalone file comes with this build.
